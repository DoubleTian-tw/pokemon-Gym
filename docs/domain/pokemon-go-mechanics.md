# Pokémon GO 遊戲機制與道館規則指南

本文件彙整《Pokémon GO》的核心玩法、道館機制與傷害倍率計算規則，作為本專案（Pokémon Gym）演算法開發、UI 呈現與功能設計的領域知識標準（Domain Knowledge Standard）。

---

## 一、 遊戲概述與基本架構

《Pokémon GO》是由 Niantic 開發營運的地理定位擴增實境（AR）手機遊戲。

- **三大陣營**：
  - **武勇隊（Team Valor / 紅色）**：以火寶可夢與火焰鳥為象徵。
  - **叡智隊（Team Mystic / 藍色）**：以急凍鳥為象徵。
  - **靈犀隊（Team Instinct / 黃色）**：以閃電鳥為象徵。
- **核心遊戲循環**：
  - 在真實地圖探索並捕捉寶可夢、旋轉寶可補給站（PokéStop）取得道具。
  - 培育寶可夢（強化 CP、進化、洗招、解鎖第二特殊招式）。
  - 道館攻防戰、團體戰（Raid Battle）、GO 對戰聯盟（PVP Trainer Battles）與火箭隊對決。

## 二、 道館防守與佔領機制

道館是遊戲中各陣營競爭佔領與玩家獲取遊戲免費貨幣（寶可幣 / 皮幣）的核心系統。

### 1. 道館配置與駐守規則
- **守衛上限**：一座道館最多可由同陣營玩家放置 **6 隻**防守寶可夢。
- **同種限制**：同座道館內**嚴禁重複放置相同編號的寶可夢**（例如已有一隻幸福蛋，其他隊友便無法再放置幸福蛋，必須選擇卡比獸、巨金怪等其他物種）。
- **進攻順序**：進攻方挑戰時，依守衛進駐道館的先後順序進行戰鬥（**先進先出，FIFO**）。打倒第一隻後才會接著挑戰第二隻，依序打至第六隻。

### 2. 幹勁系統（Motivation）與 CP 衰減
- **幹勁（愛心）**：守衛頭頂有一顆愛心代表幹勁。
- **自然衰退**：隨著駐守時間增加，幹勁與當前 CP 會自動隨時間衰減；初始 CP 越高（超過 2,300 CP），每小時衰退百分比越快（約每小時 10%），低 CP 寶可夢衰退相對緩慢。
- **戰鬥扣除**：守衛每在戰鬥中被擊敗一次，幹勁即扣除約 1/3（滿幹勁通常需要擊敗 3 次才會將其踢出道館）。
- **樹果餵食**：同隊玩家可遠端或在現場餵食樹果（蔓藤果、蕉香果、凰梨果等）回復少量幹勁與 CP；使用「金蔓藤果」可立刻將幹勁與 CP 補滿至 100%。

### 3. 佔領與皮幣獎勵（PokéCoins）
- **佔領保護**：當道館所有守衛幹勁歸零並被擊退後，道館轉為中立（白色），最後擊敗者擁有短暫優先佔領權（有 10 分鐘冷卻保護避免惡意搶佔）。
- **皮幣計算**：寶可夢防守道館每滿 **10 分鐘獲得 1 皮幣**。
- **結算上限**：皮幣在寶可夢**被擊敗返回背包時結算**，**每日全帳號上限 50 皮幣**（即便防守數天或同日回歸多隻，當日累計上限仍為 50 皮幣）。

## 三、 道館戰鬥機制

道館戰鬥屬於**即時制戰鬥（Real-time Combat）**，不同於寶可夢原作主系列遊戲（如 Switch 上的回合制 RPG）。

### 1. 對戰隊伍
- 進攻方挑選最多 **6 隻寶可夢**組成先鋒隊伍出戰。
- 可隨時手動替換場上寶可夢（換怪有短暫冷卻時間）。

### 2. 攻擊與操作
- **一般招式（Fast Attack / 小招）**：
  - 快速點擊螢幕即可發動。
  - 造成基礎傷害並累積「能量（Energy）」。
- **特殊招式（Charged Attack / 大招）**：
  - 當能量槽累積至 1 格、2 格或 3 格滿時，點擊下方蓄力招式圖示發動高額爆發傷害。
- **閃避（Dodge）**：
  - 左右滑動螢幕可進行側身閃避。
  - 成功閃避可將受到的招式傷害降低 **75%**。通常在面對守衛的大招時使用。
- **守衛 AI 特性**：
  - 防守寶可夢的血量為原本數值的 **2 倍（2x HP）**。
  - 守衛自動每隔 1.5～2.5 秒隨機發動小招，能量滿時高機率發動大招。

## 四、 傷害倍率與屬性相剋機制（重要：非原作主機遊戲規則）

《Pokémon GO》採用改編自 Gen 6+ 的 18 屬性矩陣，但**傷害倍率公式與任天堂主機上的原作主系列遊戲完全不同**：

| 相剋關係 | Pokémon GO 倍率 | 原作主系列遊戲倍率（如《朱／紫》） | 本專案中文標籤 | 說明 |
| :--- | :---: | :---: | :---: | :--- |
| **雙重弱點（雙剋）** | **$\times 2.56$** ($1.6^2$) | $\times 4.0$ | `雙重絕佳` | 防守方兩種屬性皆弱於進攻屬性（如岩打噴火龍） |
| **單一弱點（單剋）** | **$\times 1.6$** | $\times 2.0$ | `效果絕佳` | 防守方有一屬性弱於進攻屬性 |
| **一般效果** | **$\times 1.0$** | $\times 1.0$ | `效果普通` | 無相剋或相互抵消 |
| **單一抗性（單抗）** | **$\times 0.625$** ($1/1.6$) | $\times 0.5$ | `效果不太好` | 防守方有一屬性抵抗進攻屬性 |
| **雙重抗性（雙抗）** | **$\times 0.390625$** ($0.625^2$) | $\times 0.25$ | `效果極差` | 防守方兩屬性皆抗，或**原作免疫屬性在 GO 轉為此倍率** |
| **三重抗性（三抗）** | **$\times 0.24414$** ($0.625^3$) | $\times 0$ | `效果極差` | 原作免疫屬性加上另一屬性抵抗（如幽靈打一般/鋼） |

### 核心加成規則：
1. **無完全免疫（No 0x Immunity）**：原作主系列遊戲中的無效（0 倍傷害，例如地面打飛行、一般打幽靈）在 Pokémon GO 中一律降階轉化為「雙重抗性（0.390625x）」。
2. **同屬性招式加成（STAB）**：
   - 寶可夢自身屬性若與施放的招式屬性相符，獲得 **$1.2\times$ 傷害加成**（原作主系列為 $1.5\times$）。
3. **天氣加成（Weather Boost）**：
   - 真實世界對應天氣會提升對應屬性招式 **$1.2\times$ 傷害加成**。

## 五、 本專案（Pokémon Gym）實作對照與設計規範

本專案旨在解決玩家站在道館前「不知道派出哪隻進攻寶可夢最有效率」的痛點：

1. **守衛上限與輸入限制**：
   - 輸入最多 1～6 隻敵方道館守衛。
   - 支援單選、多選與全選過濾。
2. **數值與倍率精準度**：
   - 嚴格採用 Pokémon GO 的相剋倍率（`1.6` / `2.56` / `0.625` / `0.390625` / `0.24414`），不再輸出原作主系列遊戲的 `2x`、`4x` 或 `0x`。
3. **介面文字規範**：
   - 畫面上所有的相剋結果標籤，一律顯示 5 級中文文字：
     `雙重絕佳`、`效果絕佳`、`效果普通`、`效果不太好`、`效果極差`。
   - 嚴禁向使用者顯示 `2x`、`4x` 或小數點倍率數字。
4. **推薦排序原則**：
   - 第一優先：多守衛整體覆蓋率（能同時剋制越多的守衛者優先）。
   - 第二優先：相剋效果強度（`雙重絕佳` > `效果絕佳`）。
   - 第三優先：Pokémon GO 數值（基礎攻擊力 Base Attack / Max CP 較高者優先）。
5. **雙向風險標示**：
   - 進攻時除了考慮我方打點，必須同時計算敵方對我方的反打風險（以虛線與警示色標記），避免推薦雖然能剋制守衛但自身極度脆皮容易被反殺的打手。
