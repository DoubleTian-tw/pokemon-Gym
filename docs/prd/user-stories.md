# Pokémon Gym 第一版使用者故事

適用於手機瀏覽器的道館查詢。故事與驗收編號對應 [PRD](./epic-pokemon-gym-upgrade.md)。

## US-101｜選定查詢對象並篩選推薦結果（P0）

身為準備進攻道館的玩家，我想建立守塔清單，再選擇查看一隻、部分或全部對象的推薦，才能專注在當下需要的結果。

| 對應驗收 | 給定 | 當 | 則 |
| --- | --- | --- | --- |
| AC-101 | 查詢資料中有指定的守塔寶可夢 | 玩家查詢並選定該對象 | 玩家能從結果辨識這次選定的守塔寶可夢。 |
| AC-110 | 清單有至少兩隻守塔寶可夢 | 玩家只勾選其中一隻 | 結果區只顯示該對象的推薦。 |
| AC-113 | 清單有快龍、卡比獸、暴鯉龍 | 玩家只勾選快龍和暴鯉龍 | 只顯示快龍和暴鯉龍的推薦分組。取消勾選快龍後，只保留暴鯉龍的推薦。 |
| AC-114 | 清單有快龍、卡比獸、暴鯉龍，且只勾選快龍 | 玩家按「全選」 | 依清單順序顯示三隻的推薦分組。 |
| AC-115 | 推薦區只勾選一隻 | 玩家取消最後一隻 | 顯示「請至少選擇一隻守塔寶可夢」，並保留原清單供重新勾選。 |

## US-102｜找到適合進攻的寶可夢（P0）

身為道館實戰玩家，我想看到依屬性優勢排序的進攻寶可夢，並知道推薦依據，才能決定要派誰。

| 對應驗收 | 給定 | 當 | 則 |
| --- | --- | --- | --- |
| AC-102 | 可查詢的候選寶可夢中至少有一隻本身的屬性有利 | 玩家查詢守塔對象 | 結果至少推薦一隻符合條件的角色，玩家能指出該角色及有利的攻擊屬性。 |
| AC-105 | 已依 Pokémon GO 道館對戰規則核對單屬性及雙屬性的案例 | 系統依角色本身的屬性判定相剋效果 | 每筆推薦都有合併後仍有利的攻擊屬性。某一屬性的優勢若被另一屬性抵銷，不會單憑該屬性推薦角色。 |
| AC-108 | 候選的屬性效果不同，較有利的候選在舊版固定分級較低或未分級 | 系統排序當前對戰的推薦 | 較有利的候選優先，符合條件的角色可入選，不受舊版固定分級影響。 |
| AC-108 | 兩個候選對同一守塔對象的攻擊屬性效果相同 | 系統評估候選優先級 | 兩者歸同級。 |
| AC-107 | 手機原型試測已確認速度門檻 | 玩家依 PRD 的量測方式完成查詢並做出正確選擇 | 正式版達到約定的上線門檻。 |
| AC-111 | 多選結果中有兩組推薦，且各有超過 3 隻合格候選 | 玩家展開其中一組的「查看更多推薦」 | 該組顯示更多候選，另一組仍維持前 3 隻。 |
| AC-112 | 原型中的兩個守塔對象各有相剋效果相同的推薦 | 玩家切換查看推薦 | 每筆推薦都顯示標籤，效果相同的推薦顯示同一級。 |

候選有多個自身屬性時，以合併後最有利的一種攻擊屬性作為推薦與排序依據。進攻方受反擊的劣勢及可學招式不列入第一版排序，玩家可在遊戲內確認手上角色的招式。

## US-103｜分辨查詢結果與失敗狀態（P0）

身為在道館現場查詢的玩家，我想知道是找不到對象、沒有符合條件的推薦，還是暫時取不到資料，才能判斷結果是否可用。

| 對應驗收 | 給定 | 當 | 則 |
| --- | --- | --- | --- |
| AC-103 | 查詢服務可用 | 玩家查詢資料中不存在的守塔對象 | 玩家看得到查無對象的提示，並能修正查詢。 |
| AC-104 | 資料暫時無法取得 | 玩家查詢守塔對象 | 玩家知道發生暫時性問題，並能重試。 |
| AC-106 | 畫面曾顯示一筆成功的查詢結果 | 下一次查詢暫時無法取得資料 | 畫面不會把前一次結果顯示為本次答案。 |
| AC-109 | 守塔對象與候選資料均已取得 | 系統找不到任何合併效果仍有利的候選 | 玩家看得到沒有符合條件的推薦。此情境不要求提供改選操作。 |
| AC-116 | 玩家同時查看兩隻守塔寶可夢的推薦 | 其中一組暫時取不到資料 | 該組提示並提供重試，另一組維持可查看。 |

## 手機介面與驗收

先建立守塔清單，再透過單選、多選或全選篩選。結果以守塔對象分組，各組前 3 筆顯示分級與有利攻擊屬性，有其他合格候選時可獨立展開。原型暫採固定的相剋效果對照，正式版的標籤來源與各級門檻待確認。核心查詢與失敗後恢復須在 iOS Safari 和 Android Chrome 驗收。速度量測方式與門檻見 PRD。
