## 1. 頁面目標與核心任務

- **頁面目的**：讓準備攻打道館的玩家在單一畫面內完成「建立守衛陣容」與「判讀進攻打手覆蓋與反打風險」。
- **主要角色**：準備挑戰 Pokémon GO 道館的玩家（目前無會員系統，不儲存個人資料）。
- **核心任務**：
  1. 在 6 格守衛槽位中加入或移除 **1～6 隻敵方道館守衛**。
  2. 從系統自動推薦的左欄打手中，一眼看出誰能「一打多」覆蓋最多守衛。
  3. 透過**單點聚焦亮線**，同時檢視該角色的「克制目標（綠實線）」與「反打風險（橘虛線）」。
  4. 及時發現尚未被推薦打手覆蓋的守衛缺口。
- **核心 CTA**：`＋ 新增守衛`（含點選空位）、點擊畫布節點鎖定檢視、空狀態下的 `載入常見道館範例`。
- **平台尺寸**：主力為手機版 `375px – 576px`（對齊全站 `max-w-screen-sm` 與底部 `TabBar`），並提供寬螢幕 `≥ 960px` 雙欄延伸配置。

## 3. 主畫面線框圖 — 手機版（375px – 576px）

採單欄垂直流；上方採**常駐 6 格守衛槽位＋抽屜挑選**，讓手機首屏無需捲動即可完整看見打手 ⇄ 守衛連線畫布。

+-----------------------------------------------+

+-----------------------------------------------+
|                            [x] 顯示反打  [↺]  |  <- P2: 畫布控制列

|  推薦打手                             敵方守衛 |  <- 畫布內左上/右上輕量標籤

## 6. 核心互動與查詢狀態

| 情境／狀態 | 畫面表現與可用操作 |
| --- | --- |
| **空狀態（0 隻守衛）** | 畫布區不顯示空白圖表，改呈現引導說明與兩個 CTA：`＋ 新增守衛`、`載入常見道館範例`。 |
| **抽屜查無守衛** | 抽屜內搜尋不到符合項目時顯示「找不到符合的寶可夢」，保留輸入框與清除鈕，不影響已選槽位。 |
| **正常全覽（1～6 隻）** | 僅顯示節點縮圖、名稱、打手覆蓋率 `(k/N)` 與半透明連線，**預設隱藏邊標籤**避免文字重疊打結。 |
| **單點聚焦（Hover / Click）** | 無關節點與線條大幅淡化，僅亮起目標節點的實線、虛線與倍率標籤（如 `冰 4x`、`反打 2x`）；點擊鎖定時畫布下緣浮出 `✕ 顯示全部連線` 鈕，點擊同節點、畫布空白處或該按鈕即可還原。 |
| **滿編上限（6 / 6）** | 停用「＋ 新增守衛」與抽屜內未選卡片，防止超出道館 6 隻上限；仍可直接點 `x` 移除既有守衛。 |
| **覆蓋缺口（無反制）** | 若某守衛沒有任何推薦打手能打出 ≥2x，該節點外框切換為警示狀態並加註 `(無反制)`，畫布上方顯示警示條。 |
| **反打風險開關** | 取消勾選「顯示反打」時即時隱藏守衛 → 打手的風險虛線，僅保留進攻克制線。 |
| **正在取得圖鑑／對戰資料** | 抽屜與畫布區域顯示載入中占位提示，已選槽位保留顯示不閃爍。 |
| **暫時無法取得資料** | 顯示「暫時無法取得資料」與「重試」按鈕，讓玩家可重新觸發查詢。 |
| **部分反制風險無法判定** | 當守衛或推薦角色缺少判定所需屬性資料時，於畫布上方條件警示條提示部分風險尚無法判定，其餘已知連線照常繪製。 |
| **角色縮圖載入失敗** | 節點與槽位縮圖由網路載入；失敗時仍保留中文名稱與屬性標籤可供辨識。 |

## 7. 已定案決策與實作保留彈性

- **已定案（版面架構）**：採用「打手 ⇄ 守衛二分連線圖」（原混搭二），同時滿足多選守衛與雙向克制／反打關係視覺化。
- **已定案（極簡畫布）**：移除外部圖例列與 `[焦點解讀]` 面板，改於畫布內左上／右上顯示浮水印標籤，並於鎖定節點時才浮出 `✕ 顯示全部連線` 鈕，最大化保留手機首屏空間。
- **已定案（守衛選擇器）**：採用「常駐 6 格守衛槽位＋點擊展開抽屜／彈窗搜尋挑選」，手機版優先保留首屏空間給連線畫布。
- **已定案（左欄打手來源）**：固定採「系統自動推薦」（目前無會員系統，不儲存玩家個人資料）。
- **實作保留彈性**：左欄推薦打手的顯示數量（原型先以 Top 4 示意）與正式版角色分級門檻，將於串接全圖鑑 PokéAPI 實作時依手機畫面密度與測試回饋微調。

## 8. 試走可點擊原型

1. 執行 `pnpm dev`，開啟 `http://localhost:5173/pokemon-Gym/prototype`（預設即為 **「E. 混搭二：打手 ⇄ 守衛連線」**）。
2. 切換右上角「手機 576px / 寬螢幕」確認單欄與雙欄比例。
3. 點擊槽位右上 `x` 或 `清空` 測試空狀態與 `載入常見道館範例`。
4. 點擊 `＋ 新增守衛` 或 `+ 空位` 開啟抽屜，用名稱／屬性搜尋並增減至 6 隻確認上限鎖定。
5. 點擊或滑過畫布上的任一打手／守衛，驗證淡化無關線條、單獨亮線與底部焦點解讀同步更新。
